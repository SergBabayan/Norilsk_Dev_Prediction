# Анализ и Прогноз Развития Города Норильска до 2035 года

---

## Введение

Цель данного проекта — создать прогноз темпа роста валового муниципального продукта (ВМП) для города Норильска на период до 2035 года с использованием методов линейной регрессии. Для анализа и прогнозирования использованы данные за период 2015–2030 годы, включая такие показатели, как:
- Объем отгруженных товаров.
- Количество занятых в сфере малого и среднего предпринимательства.
- Инвестиции в основной капитал.
- Средняя зарплата населения.
- Уровень безработицы.
- Численность населения.

Основные шаги анализа:
1. Подготовка и анализ исходных данных.
2. Построение модели линейной регрессии.
3. Прогнозирование на основе полученной модели.
4. Оценка точности модели и интерпретация результатов.

## 2. Методология

### 2.1. Выбор моделей

Для анализа были построены две модели линейной регрессии:
1. **Первая модель**:
   - Использованы все доступные переменные: `Shipped_Goods_Volume`, `Employment_Count`, `Investments`, `Average_Salary`, `Unemployment_Rate`, `Population`.
   - Результаты показали проблемы с мультиколлинеарностью и незначимостью некоторых переменных.
   
2. **Вторая модель**:
   - Исключены незначимые переменные (`Shipped_Goods_Volume` и `Investments`).
   - Оставлены только значимые переменные: `Employment_Count`, `Average_Salary`, `Unemployment_Rate`, `Population`.

### 2.2. Разделение данных

Данные разделены на обучающую и тестовую выборки:
- **Обучающая выборка**: Данные за период 2015–2025 годы.
- **Тестовая выборка**: Данные за 2030 год.

### 2.3. Построение прогноза

Для прогнозирования периода 2026–2035 годы использованы следующие предположения:
- Количество занятых, средняя зарплата, уровень безработицы и численность населения будут расти линейно с постоянной скоростью.

#### **Основные метрики:**
- **R-squared**: `0.996`
- **Adjusted R-squared**: `0.991`
- **Mean Squared Error (MSE)**: `995.37`

#### **Проблемы:**
- **Высокая мультиколлинеарность**.
- Незначимость переменных `Shipped_Goods_Volume` и `Investments` (**высокие p-значения**).
